市面上靠谱的代充基本都走“卡密模式”，本质上相当于买一张官方充值卡：

1. 平台通过官方渠道为你的账号开通 Pro 权益，你拿到一串卡密

3. **复制用户 ID**。登录 claude.ai 后打开 Settings → Account 页面，复制那串 Organization ID / 用户 ID。注意只给 ID，不给密码，也别填成团队 ID；这一步要在已登录 claude.ai 的同一个浏览器里操作
4. **在充值系统完成直充**。粘贴卡密验证，填入用户 ID，确认升级。一般 2 到 10 分钟到账
5. **确认到账**。头像 → Settings → Billing 里看到 Pro 就成了。如果首页还显示 Free plan，先退出重新登录，Claude 的缓存问题很常见
